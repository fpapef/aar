Première version d'Aar, le détecteur d'arnaques SMS.

- Alerte dès qu'un SMS douteux arrive, avec un score de risque, les raisons et quoi faire.
- Analyse des 300 derniers SMS de la boîte de réception.
- Vérification d'un message collé, ou partagé depuis WhatsApp ou une autre appli.
- Repère les faux transferts « par erreur » (aussi en wolof), les faux avis Wave / Orange Money, les demandes de code, les faux agents, les codes USSD, les liens pièges, les faux gains, les faux proches et les promesses d'argent facile.
- Aucun accès à Internet : tout reste sur le téléphone.

**Installation** : télécharge `Aar-1.0.apk` ci-dessous, ouvre-le sur le téléphone, puis touche « Activer la protection ». Android 8 ou plus récent.
